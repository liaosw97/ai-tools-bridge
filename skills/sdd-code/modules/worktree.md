## Worktree 模块

> 本模块包含 worktree 准备、功能单元选择和目录冲突检测的完整逻辑。
> 仅在需要隔离工作环境或使用拆分模式时加载。

### 功能单元选择（拆分模式）

当 plan.md 包含 `[unit:模块/单元/功能点]` 标注时：

1. **解析功能单元状态**：
   - 遍历 plan.md 任务，提取 `[unit:...]` 标注
   - 检查每个功能单元的状态：
     - `completed`：对应任务已标记 `[x]`
     - `in_progress`：对应任务正在进行
     - `pending`：对应任务未开始

2. **输出功能单元状态列表**：
   ```
   功能单元状态：
   ① 用户管理/用户列表 — 已完成
   ② 用户管理/用户创建 — 进行中
   ③ 用户管理/用户修改 — 待开始
   ```

3. **用户选择功能单元**：
   - 默认选择第一个 `pending` 单元
   - 用户可手动选择其他单元
   - 选择后定位到对应任务范围

### 目录冲突检测（拆分模式）

在创建文件前执行以下扫描：

1. **扫描项目目录**：
   - 获取当前功能单元的目标路径
   - 扫描项目中已存在的目录结构

2. **相似目录判断**：
   - 规则：名称关键词相同或功能语义相近
   - 计算相似度：交集关键词数 / 并集关键词数
   - 阈值：相似度 > 60% 时判定为相似

3. **发现冲突时暂停**：
   ```
   ⚠️ 检测到可能已存在的功能模块：
   - [目录A路径] — 相似度 75%
   - [目录B路径] — 相似度 67%

   是扩展现有模块还是新建独立模块？
   ```

4. **用户选择处理**：
   - **选择现有目录**：记录选择，继续在该目录下工作
   - **新建目录**：检查路径冲突，如有警告用户
   - 用户确认后继续

### 功能单元独立验证（拆分模式）

当使用拆分模式时，验证范围限制：

1. **测试范围确定**：
   - 根据当前功能单元名称筛选相关测试文件
   - 规则：测试文件名包含功能单元关键词
   - 未找到相关测试时回退到全量测试

2. **验证执行**：
   - 运行筛选后的测试文件
   - 确认所有测试通过

3. **验证输出**：
   ```
   功能单元 [用户管理/用户列表] 验证通过。
   测试范围：tests/user-list.test.ts
   ```
